# NexKit sandbox

A tiny project for trying the [NexKit](https://github.com/phuongnse/nexkit) pipeline.
Run the tests with `python3 -m unittest discover -s tests -v`.

## Functions

- `mean(values)` - the average of the values.
- `median(values)` - the middle value, or the average of the two middle values.
- `mode(values)` - the most common value; on a tie, the smallest of them.
- `spread(values)` - the largest value minus the smallest.
- `variance(values)` - population variance: the mean of the squared differences from the mean.
